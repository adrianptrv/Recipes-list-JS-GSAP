# Recipe list

This is my first project using GSAP for animations.

## Overview

The idea was to create a responsive static page and try to apply as much animations I can with GSAP.

As a whole the page is pretty straightforward, there are 5 salad recipies which the user can browse are read about.

Theare are also 'add to favorite' buttons on every recipie card and trigger. When one of the two buttons for a recepie is pressed both buttons change color simultaneously, when pressed again they are no longer 'favorite' and the buttons color return to the default.

I have added animations to the **favorite button**, **recipies triggers**, **recepie card decription** and **recipie wrapper**.
